Prisma Agent Orchestrator API

Programmatically interact with distributed RAG pipelines, stream generative tokens, and supervise multi-agent worker nodes with low latency.

Authentication

All HTTP API requests require your secret API key passed as an HTTP Bearer token in the Authorization header:

HTTP HEADER 
Authorization: Bearer prisma_live_99a84b12c
// LIVE CONSOLE

Dispatch Agent Task

Submit asynchronous or real-time agent workloads to the Prisma Orchestrator cluster.

POST /v1/agents/dispatch
REQUEST EXAMPLE 
{
  "agent_id": "rag-worker-01",
  "prompt": "Analyze vector embeddings for chunk #92",
  "max_tokens": 1024
}
